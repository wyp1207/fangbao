## 5. 写链路（**授权书 + 安全员 + 急停在手**，D3）

> 红线：没授权书不碰写接口；首次限速；人员离机器人 ≥ 3m；异常先急停再排查。

| # | 操作 | 判据 | 不过怎么办 | 结果 |
|---|---|---|---|---|
| 5.1 | 打开写开关 | 开关生效，审计有记录 | — | ☐ |
| 5.2 | 预检：电量、急停、在线、无占用 | 预检通过 | 有一项不满足就停下 | ☐ |
| 5.3 | **暂停/继续** | ⚠️ JCROB 无独立暂停接口，应返回 501 并解释 | 不要假装支持；改用取消 | ☐ |
| 5.4 | 下发**单点任务**（1 个点位） | 出发→到点→停；平台 `task_run` 状态 待执行→执行中→完成 | 无响应：立刻 cancel + 急停 | ☐ |
| 5.5 | 连续 3 次单点 | 3/3 成功；平台时间戳与实际 < 5s | 2 次失败 → 停止写测试 | ☐ |
| 5.6 | 取消任务 | 车停；平台状态 `cancelled`；**不能把 UNKNOWN 当已停** | 车仍在走 → 急停 | ☐ |
| 5.7 | 任务中按急停 | 平台状态变 failed/中止；审计记录 | 状态不一致 → 禁止无人值守 | ☐ |
| 5.8 | 重复下发同一订单（幂等） | 只产生 1 个任务（order_id 唯一） | 重复执行 → 关写开关 | ☐ |
| 5.9 | 断网后恢复 | 任务能否续跑/补录；不能就写明 | 合同注明"断网不补" | ☐ |

## 10. 失败回退矩阵（现场决策，不许临场发挥）

| 现象 | 先查 | 处置 | 放弃条件 |
|---|---|---|---|
| 连不上 3546 | 网络/ firewall / 端口 | 直连网线；客户 IT 开端口 | 2 小时仍不通 → 当天只做本地演示 |
| 字段缺/类型不同 | 原始 JSON vs 文档 | 适配器加兼容分支（只加不删） | 缺写操作必需字段 → 写链路顺延 |
| 时钟偏差 > 5s | NTP | 客户对时；报表标注 | > 60s 必须解决 |
| 坐标对不上 | 比例尺/原点 | 平台标定；或直显机器人坐标 | > 2m 禁止下发点位 |
| 下发无响应 | 是否收到 | cancel + 急停；抓车端日志 | 连续 2 次 → 停写测试 |
| 急停后状态不变 | 上报频率 | 平台强制 failed + 审计 | 状态长期不一致 → 不允许无人值守 |
| 相机不出图 | RTSP/网关/编码 | 直连优先；H265 走 `_web` | 2 小时不通 → 用手机拍 |
| 云台不动 | ISAPI/账号/通道 | 用厂商工具先验证 | 厂商接口不支持 → 只做抓拍 |

## 12. 必须实话实说的（别等客户发现）

| 项 | 现状 |
|---|---|
