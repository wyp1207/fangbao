# 平台评价：客户 / 普通观众 / 专业工业运维 三视角

你同时是三个人，请**分别**以这三种身份评价下面这个平台，并**查资料对照**（大厂方案、成熟案例、应急管理局/石化行业安全平台、GitHub 开源项目）。

## 一、平台事实（不要假设更多）

**是什么**：单台轮式防爆巡检机器人（JCROB）的网页管理平台，客户内网部署（192.168.8.40，nginx 8099），交付 2026-12-01，真机 2026-11-10 到现场。

**已实现**：
- 首页大屏：场站/设备切换、时钟状态带（电量/在线/定位/机器人状态/服务器状态）、可见光+热红外窗口（占位）、实时控制面板（云台/车体页签+摇杆，写操作锁定）、实时地图（SLAM 栅格图+机器人位姿+点位+轨迹拖尾）、实时消息、告警统计环图、环境数据（未接入占位）、巡检点位列表；顶部有锁屏、告警、消息中心、全屏、账号菜单
- 实时监控：机器人状态、地图监控、视频监控（go2rtc MSE ~0.5s）、充电房监控、环境监测（占位）
- 巡检管理：任务管理（只读+详情+动作序列）、巡检点位（只读）、任务日历（占位）
- 告警中心：告警记录（筛选/分页/确认）、告警规则（阈值只读）
- 数据查询：任务数据、告警数据、CSV 导出、运行数据（占位）
- 设备管理：机器人（JCROB/宇树 G1/云深处 X30 待接入 + 能力矩阵）、摄像头（RTSP CRUD + go2rtc 一键注册 + 密码打码）、环境传感器（占位）
- 录像管理：录像计划（**当前暂停落盘**，保留策略待定）、录像回放（Range 点播/下载/删除）
- 系统管理：用户管理（CRUD/角色/重置密码）、系统设置（能力探测/运行状态）、系统日志（占位）
- 消息中心：告警 + 视频/账号/系统事件（内存，重启清空）

**明确没有**：云台控制、AI 识别、环境传感采集、多机器人调度、写操作（任务下发/点位编辑，等授权）、历史数据库（W5）、告警与摄像头/任务的关联、3D/数字孪生。

**技术栈**：Vue3 + FastAPI + SQLite/PostgreSQL + go2rtc + ffmpeg，单开发者，一套 Docker Compose。
