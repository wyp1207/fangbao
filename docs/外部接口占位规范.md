# 外部接口占位规范（先定契约，后接设备）

> 目的：JCROB 目前能提供机器人本体数据，但 BMS、固定设备、AI 识别、气象站、人脸、门禁等能力并不在协议里。按你的要求，先把平台内部接口和数据格式定下来；设备到位后只实现 Adapter，不改前端和业务库。
>
> 原则：**没有数据就显示“未接入”，不要用 0、空数组或假曲线冒充正常数据。**

## 1. 统一约定

- 平台内部 API 前缀：`/api/v1`
- 认证：`Authorization: Bearer <JWT>`
- 时间：ISO 8601，带时区，例如 `2026-10-20T12:00:00+08:00`
- 单位：电压 V、电流 A、温度 ℃、湿度 %RH、距离 m、角度度（对外 API 统一度；Adapter 内部可转弧度）
- 所有“外部设备”都带 `source` 和 `observedAt`，方便判断数据新鲜度
- 外部适配器失败时返回 `503` + `code=EXTERNAL_UNAVAILABLE`，不要返回 200 + 空数据

统一响应：

```json
{
  "code": "OK",
  "message": "",
  "data": {},
  "traceId": "b7c1f0e2"
}
```

错误码：

| code | HTTP | 含义 |
|---|---|---|
| `OK` | 200 | 成功 |
| `BAD_REQUEST` | 400 | 参数错误 |
| `UNAUTHORIZED` | 401 | 未登录/token 失效 |
| `FORBIDDEN` | 403 | 无权限 |
| `NOT_FOUND` | 404 | 资源不存在 |
| `CONFLICT` | 409 | 设备忙/任务冲突 |
| `EXTERNAL_UNAVAILABLE` | 503 | 外部设备/适配器不可用 |
| `EXTERNAL_TIMEOUT` | 504 | 外部设备超时 |

## 2. 能力注册表（前端先接这个）

## 4. 固定设备控制（门/灯/空调/充电柜）

`POST /api/v1/devices/{deviceId}/commands`

```json
{
  "command": "door.open",
  "params": {},
  "requestId": "c0a80101-7f3e-4f4e-9d5c-1a2b3c4d5e6f"
}
```

命令枚举：

| command | params | 说明 |
|---|---|---|
| `door.open` / `door.close` | `{}` | 门禁 |
| `light.on` / `light.off` | `{}` | 照明 |
| `ac.on` / `ac.off` | `{"temperature": 26}` | 空调 |
| `charger.on` / `charger.off` | `{}` | 无线/有线充电电源 |
| `elevator.call` | `{"floor": 3}` | 电梯 |

返回：

```json
{"code":"OK","data":{"command":"door.open","accepted":true,"finishedAt":"2026-10-20T12:00:03+08:00"}}
```

没有适配器时：命令返回 `EXTERNAL_UNAVAILABLE`；前端按钮置灰，tooltip 显示“未配置设备适配器”。不要在前端直接发 Modbus/MQTT。

## 5. AI 巡检（点位识别/表计/缺陷）

`POST /api/v1/ai/inspect`

```json
{
  "deviceId": "robot-001",
  "inspectionPointId": "point-003",
  "imageUrl": "http://minio/.../snapshot.jpg",
  "algorithm": "meter_reading",
  "roi": [[0.12, 0.20], [0.48, 0.20], [0.48, 0.62], [0.12, 0.62]],
  "requestId": "0f0e0d0c-1111-2222-3333-444455556666"
}
```

返回：

```json
{
  "code": "OK",
  "data": {
    "algorithm": "meter_reading",
    "confidence": 0.93,
    "value": "1.25",
    "unit": "MPa",
    "alarms": [],
    "annotatedImageUrl": "http://minio/.../annotated.jpg"
  }
}
```

没有 AI 服务时：任务照常执行并保存原图；结果字段为 `null`，前端显示“未识别/待人工确认”。不要生成假识别结果。

## 7. 人脸/门禁/对讲/消防/电梯/UPS/NVR

这些能力先只定路径和最小字段，不实现：

| 能力 | 路径 | 最小字段 | 当前策略 |
|---|---|---|---|
| 人脸识别 | `POST /api/v1/face/verify` | `image`, `faceLibId` → `matched`, `personId`, `score` | 菜单隐藏 |
| 门禁 | `POST /api/v1/access/command` | `doorId`, `action: open/close` | 按钮置灰 |
| 对讲 | `POST /api/v1/intercom/session` | `deviceId`, `protocol: webrtc/sip/gb28181` | 隐藏按钮 |
| 消防/固定气体 | `GET /api/v1/fire/status` | `smoke`, `lel`, `temperature`, `alarm` | 只显示机器人移动监测 |
| 电梯 | `POST /api/v1/elevator/command` | `floor`, `action: call/open/close` | 跨楼层任务禁用 |
| UPS | `GET /api/v1/power/ups` | `inputVoltage`, `outputVoltage`, `battery`, `load` | 显示“未接入” |
| NVR/GB28181 | `POST /api/v1/media/register` | `deviceId`, `channelId`, `streamUrl` | 只用 RTSP 预览 |
| 工单/ERP | `POST /api/v1/workorders` | `alarmId`, `assignee`, `status` | 告警只在本平台闭环 |

## 8. 前端“未接入”行为矩阵

| 场景 | 错误/状态 | UI 行为 |
|---|---|---|
| BMS 未接入 | `EXTERNAL_UNAVAILABLE` | 卡片显示“未接入”，不画曲线 |
| 固定设备未配置 | `EXTERNAL_UNAVAILABLE` | 按钮置灰，tooltip 说明原因 |
| AI 未配置 | `data.result=null` | 显示原图 + “待人工确认” |
| 视频断流 | WS/媒体网关 `stale` | 显示最后一帧 + “信号中断”遮罩，不显示黑屏当正常 |
| 任务下发失败 | `CONFLICT` | 显示机器人当前状态和拒绝原因 |
| 数据超时 | 超过阈值未更新 | 显示“数据已过期”，不是 0 |

## 9. 版本与安全

- 外部接口按 `/api/v1` 版本化；破坏性变更升 `/api/v2`
- 适配器凭据只放后端环境变量/密钥管理，不入库明文、不下发前端
- 所有写命令带 `requestId` 做幂等；超时重试前先查状态
- 外部设备控制必须记录操作者、命令、参数、结果、耗时
- 没有厂家书面确认的 IO/充电/门禁命令，默认禁用
