## 3. 现在**真的能演示**的功能（带验证路径）

> 以下都在 8.40:8099 的 mock 模式（`robot_mode=mock`）下可复现。

### 3.1 驾驶舱大屏（首页）

| 功能 | 怎么验 | 预期 |
|---|---|---|
| 四块布局 | 打开 `/dashboard` | 视频 / 3D 地图 / 告警统计 / 环境数据 同屏 |
| 实时位姿 | 看 3D 里机器人标记 | 每秒刷新，WS 200ms（HUD 显示 `WS 200ms`） |
| 3D 拖拽 | 鼠标左键拖 3D 区域 | 视角旋转；**拖拽不弹确认框** |
| 点哪去哪 | 3D 里点一下地面 | 弹"让机器人去 x,y？"确认框（mock 下会 409 拒绝，属预期） |
| 环境数据 | 右栏 | 传感器按类型合并，过期显示"离线 / N 天前" |
| 今日任务状态 | 中间下方 | 从 `/task-runs` 动态取，10 秒刷新；无任务显示"当前无任务" |

### 3.2 3D 数字孪生

## 5. 现在**可以对外承诺**的功能边界

**可以承诺（演示可复现）**

- 单机巡检全流程（模拟器）：模板 → 下发 → 逐点 → 到点动作 → 报告
- 告警闭环：分级/去重/搁置/工单/通知/审计
- 3D 孪生：实时位姿、轨迹回放、告警空间定位
- 视频：可见光 + 热红外（按相机配置）、云台方向/预置位
- 权限与安全：RBAC、TOTP、锁屏、审计链、设备密钥
- 运维：自检、健康、备份恢复、容器化部署

**不能承诺（需真机/第三方）**

- 真机到点精度、断网续跑、急停后状态一致性
- 多机协同、跨地图任务
- 规划路径可视化（除非车端开放）
- 等保/防爆认证、7×24 稳定性

## 6. 第三方验证建议（给 ChatGPT / 评审人）

请按这个顺序核对，**每条都能在代码或页面上找到对应物**：

1. **代码规模**：`grep -r "@router\." server/app/api | wc -l` 应 ≈184；`ls server/alembic/versions | wc -l` = 25
2. **测试**：`cd server && python -m pytest -q` → 143 passed
3. **接口**：打开 `http://192.168.8.40:8099/docs`（若开启）或看 `contracts/openapi.json`
4. **页面**：登录后逐页对照第 3 节，重点验：
   - 3D 拖拽是否旋转、点地面是否弹确认
   - 视频是否真实画面（不是占位图）
   - 告警搁置是否必填原因
   - 任务报告 xlsx 是否能打开
   - 自检是否逐项给建议
5. **诚实性**：对照第 4 节，随机挑 3 项确认"确实没做"，而不是藏起来
6. **数据真伪**：确认演示数据是 mock（`/health` 里 `robot_mode=mock`），不要把 mock 当真实机器人
