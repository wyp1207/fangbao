# 功能模块清单 + 首页建模方案 评审提示词（豆包 / GLM）

你是做过**工业巡检平台**的产品经理 + 全栈工程师。请输出两部分，直接给结论，不要客套。

## 一、项目事实（已定稿，不要改动）

**本体**：单台轮式防爆巡检机器人（JCROB），HTTP 3546 `/api/v1` + WebSocket 3547；机器人自己做 SLAM、定位、路径规划、避障。
**排期**：真机 2026-11-10 到现场，交付 2026-12-01。**单开发者**。
**部署**：客户内网 192.168.8.40（Ubuntu 22.04，52 个容器），nginx 端口 8099，纯内网，无外网。
**已接的其它设备**：客户现有一套 go2rtc（RTSP :8554 / API :1984 / WebRTC :8555），已有 15 路海康相机；即将接宇树 G1 人形、云深处 X30 机器狗（SDK 未定）。

**平台上已有/可用的真实数据**：
- 实时状态：位姿 x/y/angle、电量、电压、速度/角速度、导航状态、急停 driver_button、当前任务
- 地图：地图列表、当前地图、地图 PNG 切片、巡检点 nav_points（读）
- 任务：任务列表、任务详情、动作序列（只读）
- 告警：电量低/急停/通信中断（平台侧规则）+ 确认
- 视频：go2rtc 流名 → MSE 播放（~0.5s）；另有 MJPEG 兜底
- 系统：能力探测、健康检查、用户与角色、视频源 CRUD、go2rtc 流注册

**明确没有的**：视频云台控制、环境传感器（气体/温湿度/噪声设备未定）、AI 识别（不在合同）、历史报表（W5 才落库）、多机器人调度（只有一台）、写操作（全部锁着，等真机 + 授权签字）。

**已实现的页面**：驾驶舱、机器人状态、地图监控、视频监控、充电房监控、任务管理、巡检点位、告警记录、告警规则、数据查询（任务/告警 CSV）、用户管理、系统设置、设备管理（机器人/摄像头）、录像管理（占位）。

## 二、请产出

### 第一部分：功能模块清单（表格）

按下面的列输出 Markdown 表格，**每行一个功能点**，覆盖到"验收时能逐条打勾"的粒度：

| 模块ID | 模块 | 功能ID | 功能名称 | 角色（管理员/操作员/只读） | 功能描述（25字内） | 依赖接口 | 数据来源 | 本期状态（已做/待做/占位/不做） | 优先级 |
