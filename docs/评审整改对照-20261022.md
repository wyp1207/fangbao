## 三、我认同但**本轮不改**的

1. **任务下发写链路**：必须等真机协议确认，现在写等于瞎猜；这是 12/01 交付的最大风险。
2. **等保三权分立**：会改所有接口的权限判断，建议真机联调后做。
3. **50 路视频容量**：架构级决策（NVR/对象存储/事件录像），不是代码问题。
4. **AI 算法本体**：不在我们范围；平台只负责结果接入（已打通）。

## 四、复盘：哪些是我"闭门造车"做差了的

| 我的做法 | 行业做法 | 现在 |
|---|---|---|
| 登录锁定只放内存 | 落库 + 失败计数表 | 已改（`login_attempt`） |
| TOTP 只校验不防重放 | RFC 6238 部署要求记录最后计数器 | 已改 |
| 登出只删 Cookie | JWT 要有版本号/黑名单 | 已改（`token_version`） |
| 告警只能人工关闭 | 条件消失应自动 resolved | 已改（`resolved_at`） |
| 健康检查只看进程 | liveness/readiness 分开，readiness 查库 | 已加 `/ready` |
| 审计链没有轮换/校验入口 | 哈希链 + 校验接口是标准配置 | 已加 `/audit-logs/verify` |
