## 关键设计（请重点评这个）

巡航 = **平台逐点下发 + 等到达 + 到点执行动作**：
1. 平台按点位顺序取 (x,y,yaw)；
2. 调适配器 goto/1003 下发单点目标；
3. 每 3 秒查任务状态，FINISHED 且位姿误差 <1.5m 才算到点；
4. 到点执行动作（拍照/测温/停留），结果写 task_run_step；
5. 下一个点；取消则停线程 + 取消机器人当前目标。
