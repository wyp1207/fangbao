| # | 演示动作 | 预期结果 | 备用说明 |

## 五、被问到时必须实话实说的 5 句

1. **"现在能跑几台车？"** → 软件支持多台接入；当前只有 1 台真机，多机协同未实车验证。
2. **"断网了怎么办？"** → 平台侧会标离线并告警；机器人自主续跑依赖本体能力，未验证。
3. **"数据存哪、会不会丢？"** → 默认 SQLite 单文件，支持 MySQL；每日自动备份 + 恢复演练已做。
4. **"等保能过吗？"** → 应用层安全做了；等保测评和防爆认证需要第三方，不在本次范围。
5. **"和某头部比差在哪？"** → 他们有成百上千台落地、全链路 HIL 测试；我们是单机试点级，差距在真机验证与规模化。

## 六、已知缺陷（主动说，别等对方发现）

| 缺陷 | 影响 | 计划 |
|---|---|---|
| 单 worker / 无 MQ | 多设备高频上报会拖慢接口 | 真机验证后按需引入 MQ + 时序库 |
| 无容器化/灰度 | 升级中断 10–20 秒 | 需要零中断时再做多实例 |
| 单地图 | 跨区域不可用 | 多地图为下一阶段 |
| 点位/告警有历史测试数据残留 | 演示时可能出现奇怪文案 | 演示前跑 `clean_demo_data.py` |
