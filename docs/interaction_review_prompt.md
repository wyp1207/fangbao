# 模块联动检查清单（豆包 / GLM）

你是做过工业巡检/SCADA 平台的产品经理。请给一份**模块联动矩阵**，用来检查"页面之间有没有断链"。

## 我们的模块（已实现）

- 首页驾驶舱：场站/设备切换、状态带、可见光/热红外窗口、实时控制、实时地图、实时消息、告警统计、环境数据、巡检点位
- 实时监控：机器人状态、地图监控、视频监控、充电房监控、环境监测（占位）
- 巡检管理：任务管理、巡检点位、任务日历（占位）
- 告警中心：告警记录、告警规则
- 数据查询：任务数据、告警数据、运行数据（占位）
- 设备管理：机器人、摄像头（RTSP + go2rtc 注册）、环境传感器（占位）
- 录像管理：录像计划、录像回放
- 系统管理：用户管理、系统设置、系统日志（占位）

真实数据：位姿/电量/急停/导航状态、地图 PNG、巡检点、任务与动作序列、告警（电量低/急停/离线）、视频（go2rtc MSE）、录像分段、用户角色。

## 请输出

### 1. 联动矩阵（表格）

列：`源模块.元素` → `点击/操作后应该发生什么` → `落到哪个模块（带什么上下文）` → `优先级(必须/建议/可选)`。

要求覆盖这些"天然该联动"的地方，至少 18 行：
- 首页告警统计/告警条目 → 告警中心（带筛选）
- 首页巡检点位 → 地图定位/点位详情
- 首页实时消息 → 告警记录
- 告警记录某条 → 地图定位/关联视频/任务
- 任务详情里的点位 → 地图上高亮
- 视频监控某路 → 设备管理里的摄像头配置
- 摄像头列表 → 视频监控预览（带该路）
- 录像回放某段 → 关联任务/告警
- 机器人状态 → 地图/视频
- 系统设置能力探测 → 影响其他模块可用性提示
- 顶部告警徽标 → 告警中心
- 顶部锁/铃/信封图标

### 2. 现在最可能断的 5 条

按"领导点了会觉得不专业"的程度排序，每条写：现象、为什么会这样、怎么补（一句话）。

### 3. 不该做联动的

哪些看起来能联动、但做了反而添乱（例如告警没有坐标就不该跳地图定位）。最多 3 条。
