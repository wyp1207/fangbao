# 用户能自己配什么？在哪配？（阈值 / 采集 / 告警 / 保留）

> 原则：**读数不用人填，配置项全部可改**。
> 阈值有优先级：**外设规则 > 传感器自身阈值 > 全局默认**。

## 1. 传感器阈值（最常改）

**位置**：设备管理 → 环境传感器 → 某一行 → ✎ 编辑

| 字段 | 含义 |
|---|---|
| 提醒上限 / 严重上限 | 数值 **≥** 它就报 warn / critical |
| 提醒下限 / 严重下限 | 数值 **≤** 它就报 warn / critical |
| 单位 / 位置 / 备注 | 仅展示用 |

留空 = 该方向不判。

## 2. 外设上的告警规则（优先级最高）

**位置**：设备管理 → 外设管理 → 某外设 → 「规则」

| 项 | 说明 |
|---|---|
| 启用告警 | 关掉后这条外设**只记读数、不报警** |
| 提醒/严重 上下限 | 覆盖传感器自身的阈值 |

**为什么要两层**：传感器是"物理探头"，外设是"装在哪台车上"。
同一型号探头装在不同车/不同区域，阈值可能不同；换车时只改外设，不动探头。

编辑弹窗里会显示「实际生效来源」，避免"改了传感器阈值却没生效"。

## 3. 采集参数（网关）

**位置**：设备管理 → 采集网关 → 新增/编辑

| 字段 | 说明 |
|---|---|
| 协议 | modbus(TCP) / modbus_rtu_ssh(串口经 SSH) / mqtt |
| 主机 / 端口 / 单元号 | modbus 用；串口协议里 port 复用为波特率 |
| 串口路径 | 串口协议里 topic 字段复用为 /dev/ttyUSB0 |
| 采样间隔 interval_s | 默认 10s，最小 3s |
| 寄存器映射 | [{sensor_id, register, scale, function}] |

## 4. 全局告警规则

**位置**：告警中心 → 告警规则

| 项 | 说明 |
|---|---|
| 电量提醒 / 严重 | 百分比 |
| 离线判定 | 秒（X30 适配器会自己声明更长的阈值） |
| 持续多久才报 / 去重窗口 | 防抖 |
| 升级规则 | 5 分钟内第 N 次自动升级为严重 |

## 5. 保留与容量

**位置**：系统设置

| 项 | 默认 |
|---|---|
| 遥测保留天数 | 7 |
| 环境读数保留天数 | 90 |
| 录像保留天数 / 容量上限 | 30 天 / 800GB |
| 磁盘停录阈值 | 5GB |
| 写操作开关 | 关（真机联调后现场签字再开） |

## 6. 设备与外设

**位置**：设备管理

- 机器人：名称/场站/IP/端口/适配器/启用
- 外设：类型/厂商/型号/通道/关联传感器或视频/启用
- 摄像头：地址/分组/是否上大屏
- 采集网关：见第 3 节

## 7. 不能改的（设计上锁死）

- 审计日志（只读，哈希链保证不可改）
- 告警/工单历史（只能关闭，不能删）
- 协议帧格式（厂商固定，改了就连不上）

## 8. 测试建议（本机，不碰 8.40）

1. 环境传感器 → 编辑气体传感器：提醒上限 100、严重上限 200
2. 用「环境传感器」页的手工录入或 API 推一个值 150 → 应出 warn
3. 外设管理 → 同一传感器 → 规则：提醒上限 50 → 再推 150 → 应出 critical（外设优先）
4. 关闭该外设告警 → 再推 999 → 不产生告警，但读数仍在历史里
5. 采集网关 → 把间隔从 10s 改 5s → 读数频率翻倍
