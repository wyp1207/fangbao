## 系统现状（真实，不是设想）

单机部署：FastAPI + MySQL + Vue3 + go2rtc + ffmpeg，单 uvicorn worker。
设备：云深处 X30（TCP 30000 状态、UDP 43893 起立/趴下）、JCROB 轮式（HTTP 3546 + 环境传感器 WebSocket 3547）、JCROB 模拟器。

模块：
- 登录：JWT httpOnly cookie + CSRF 双提交；7 角色（admin/sysadmin/secadmin/auditor/safety/operator/viewer）；TOTP；登录锁定 5 次/10 分钟；空闲 5 分钟自动退出（可配）
- 首页大屏：三栏（左视频+控制、中地图+实时消息、右告警统计+环境+点位）；按外设能力派生面板
- 视频：go2rtc 转码（H265→H264 _web 变体）+ 服务端共享 ffmpeg MJPEG；每路一个转码进程，无人看自动停
- 告警：阈值（外设规则优先）→ 持续 N 秒 → 滞回 → 去重 → P1-P4 分级 → 转工单（SLA 时限）→ 超时升级；支持搁置（有原因有期限）
- 工单：派单、手机 H5 接单拍照销号、超时升级
- 任务：模板（拍照/录像/停留/云台/测温）→ 执行记录 → 巡航（逐点下发+轮询+到点动作）；写开关默认关
- 环境：JCROB 两路 WS（EnvSensorData + AirSensorData）→ 自动建传感器+外设 → 阈值告警
- 报表：巡检/考核/覆盖度/响应闭环/SLA 按期率；Excel 导出；审计哈希链 + 一键校验
- 系统状态页：设备运行时 / 视频转码 / 采集网关

已知：真机巡航没跑过；X30 站外不可达；部分历史数据是测试数据。
