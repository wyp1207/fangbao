# 请提出 20 个问题：这个平台放生产会出什么事

你同时是三个人：**专业观众**（懂行但不碰代码的甲方技术负责人）、**专业产品经理**、**资深软件工程师/架构师**。
请针对下面这个平台，提出 **20 个尖锐问题**（不是表扬，是挑毛病），并按"放生产环境会有什么后果"排序。

## 平台事实（只有这些，不要假设更多）

**场景**：单台轮式防爆巡检机器人（JCROB），化工/石化厂区，内网部署，2026-12-01 交付，真机 2026-11-10 到场。
**技术栈**：Vue3 + TS + Vite 前端；FastAPI + SQLAlchemy + MySQL/SQLite；go2rtc 视频；ffmpeg 录像；Docker Compose 单机部署。

**已实现（真的能跑，不是画饼）**：
- 首页大屏：场站/设备、状态带、内嵌视频（go2rtc MSE）、SLAM 2D 地图+位姿+轨迹、实时消息、告警环图+近 7 日趋势、环境数据、点位列表
- 地图：机器人地图只读；平台地图库（上传 PNG、人工填分辨率/原点、与机器人地图名映射）；点击地图打点存草稿（未下发）
- 巡检：任务/点位只读（列表、详情、动作序列）
- 告警：电量/急停/离线三类平台推导告警；环境传感器超限；确认→处置→关闭闭环；CSV 导出；一键回看该时刻录像
- 环境：传感器 CRUD、四档阈值（留空=未标定）、读数历史、24h 趋势
- 设备：设备台账 CRUD、连接参数、TCP/HTTP 连通性测试、协议注册表（未实现协议标"待接入"并列出缺什么）
- 视频：摄像头 CRUD、go2rtc 一键注册、MJPEG/HLS/MSE 兜底、录像（分段 mp4 + 保留策略 + 磁盘保护）、定时录制计划
- 系统：用户/角色、系统设置（14 项，落库即时生效）、操作审计、消息中心、告警外发（企微/钉钉/webhook/邮件，带静默期）、全站能力异常黄条
- 运行数据：每 10 秒采电量/电压/速度/位姿，7 天保留，曲线 + 里程 + 离线占比

**明确没做**：
- 所有机器人写操作（任务下发/暂停/取消、点位下发、地图下发、云台控制）——等真机+授权
- AI 识别、红外测温、3D/数字孪生、多机器人调度、GB28181/OPC UA/DCS 对接、监管平台上报
- 报表（周报/月报导出）——正在做
- 多机器人：目前轮询只盯 1 台

**已知取舍**：
- 单 uvicorn worker（后台轮询/队列都在进程内）
- 告警阈值留空即"未标定"，不告警
- 地图只有 2D 栅格

## 输出要求

20 个问题，每条按这个格式：

```
Q<编号>｜<一句话问题>
- 谁会问：领导 / 运维 / 安全 / 开发
- 现在的答案：（基于上面事实，能答就答，不能答就说没有）
- 放生产的后果：（掉数据 / 被问责 / 演示翻车 / 后期返工 …，具体点）
- 危险等级：高 / 中 / 低
```

要求覆盖（但不要只写这些）：
1. 单点故障：机器挂了、MySQL 挂了、容器重启，现场会怎样
2. 数据一致性：告警/录像/遥测三份数据时间对不上怎么办
3. 权限：只有 admin/operator/viewer 三类够不够，谁能改阈值
4. 安全：内网无 TLS、Cookie、CSRF、密码策略、审计能不能满足等保
5. 告警可信度：误报漏报怎么算账，去重与静默期会不会吃掉真实告警
6. 视频：go2rtc 挂了对首页/告警回看的影响，录像与告警时间对齐精度
7. 地图：分辨率填错会怎样，点位坐标错了下发出去会撞什么
8. 多机器人：为什么现在只支持一台，扩展到 10 台会先崩在哪
9. 交付：没有报表、没有 AI、没有 3D，客户验收会不会卡
10. 运维交接：出问题谁能修、日志够不够、备份恢复演练过没有

最后一句话总结：**如果明天就上线，最可能出的三个事故是什么**。
