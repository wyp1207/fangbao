A. **程序化 3D（地图驱动）**：把 2D 栅格地图当高度场，墙/障碍按占据栅格拉高，叠加点位/机器人/告警/轨迹；坐标天然对齐（同一 SLAM 系）。

D. 不做 3D，继续 2D 大屏。
