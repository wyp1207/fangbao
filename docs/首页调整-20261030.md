## 2. 环境数据"乱码"

真实原因不是编码问题，是**三个同类传感器 + 过期数据挤在一行**：

- 同场站建了 3 个"可燃气体"传感器 → 面板渲染 3 格
- 其中 2 格没数据、1 格是 2 天前的旧值
- `离线`、`2 天前`、`-- %LEL` 全挤在数值行 → 看起来像乱码

改法：

1. **按类型合并**：每类只显示一格，取最新读数，右上角标 `1 类 · 3 个`
2. **单元格三行**：标签+离线 / 数值 / 数据年龄
3. **过期不装真**：超过 120 秒没有新读数，显示 `--` 并标"离线"

> 顺带回答"传感器是实时的吗"：平台以前会把最后一条历史值当当前值显示，这是误导。
> 现在带 `age_s/stale`，过期就明确标离线。

## 3. 车体控制（按 SDK 能力分流）

| 机型 | 能不能自己走 | 界面 |

默认页签改为**云台控制**（未启用云台时才落车体）。

## 4. 实时地图默认 3D

- `viewMode` 默认值从 `2d` 改为 `3d`，进首页直接是三维视图
- 删掉地图上两层装饰：`.scan`（上下扫光）和 `.radar`（**循环旋转的白色锥形屏障**）
- 删除原因：旋转层是绝对定位覆盖在 `.map-frame` 上，切到 3D 后依然盖在三维场景上，既挡视线又容易被当成"渲染故障"

## 5. 任务报告导出

- 任务信息（编号/状态/设备/起止/成功失败数）

- 任务期间告警（时间/级别/内容/确认状态）
- 任务列表每行「报告」按钮直接下载
