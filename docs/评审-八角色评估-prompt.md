## 一、平台事实（截至 2026-10-28）

**业务**：防爆巡检机器人平台（轮式 JCROB + 四足云深处 X30），Web 大屏 + 后端 + 设备适配。
**技术栈**：Vue3 + FastAPI + SQLAlchemy + SQLite/MySQL（**单 uvicorn worker**）。
**部署**：客户内网单机部署（192.168.8.40:8099）；无 Docker/K8s、无 MQ、无 Redis、无时序库、无对象存储。
**设备接入**：
- JCROB：HTTP 3546 + WS 3547（环境传感器推送）
- X30：TCP 30000（XML 协议 1002/1003/1004/1007/2001/2101）、UDP 43893（起立/趴下）
- 视频：go2rtc（H265→H264 转码 + MJPEG 推流），支持换流/改地址/无人观看自动停
**已实现能力**：
- 任务：模板→执行记录→单点/逐点巡航→到点动作（拍照/测温/停留）→状态机（5 主态 + dispatch_state 正交字段）
- 下发幂等：order_id 唯一 + 先落库再发 + 对账（`JC-R{run}-A{attempt}`）
- 到点三态：arrived / arrived_suspect（疑似定位漂移，不重试）/ failed
- 多机：一车一任务互斥 + 人工接管 + 进程内资源锁（点位/充电桩/区域）
- 告警：阈值规则引擎（sustain/回差）、P1–P4 分级、SLA 矩阵、搁置（到期自动解除、期间暂停升级）、告警↔工单双向
- 定位：X30 2101 重置定位 + 读回校验（located + 0.5m）；定位丢失告警与首页横幅
- 环境：JCROB WS 双主题接入（温湿度/烟感/PM/LEL/噪声/CO2/照度）
- 安全：JWT httpOnly + CSRF 双提交、scrypt、TOTP、RBAC（admin/operator/safety/viewer）、审计哈希链、写开关
- 运维：系统状态页（设备运行时/视频转码/采集网关）、保留期清理、遥测聚合、磁盘监控、看门狗

- 联调套件 24/24（前端契约、业务闭环、数据库、规则引擎、网关、时延/并发/幂等/稳定性/一致性）
