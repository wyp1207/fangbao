# 浸泡测试与运维加固（2026-10-28）

## 1. 3 分钟浸泡（3144 次请求）

```text
请求 3144 次，错误 0 次
p50=6ms  p95=13ms  max=76ms
内存：起始 220.8MB → 结束 208.5MB（峰值 221.3MB）
审计链：{'ok': True, 'checked': 1253}
```

**结论**：短时无泄漏、无错误、审计链稳定。**但这不等于 7×24 通过**——10 分钟以上、
带视频转码与真机上报的浸泡还没做（见 §4）。

复跑：`python scripts/soak_10min.py --minutes 3`
