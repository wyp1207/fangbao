# 模型评审记录 20261030-162507

## 智谱 glm-5.2

1. **任务状态区布局**
- **优先级**：状态 > 剩余时间 > 任务名。
- **字号/行高**：状态标签32px、剩余时间28px、任务名24px；大屏最低字号不低于20px。行高设为1.5倍。
- **换行/截断**：**坚决不用省略号**。改为“左右分栏”排版，左侧任务名限宽自动换行（最多2行），右侧紧贴显示剩余时间。若空间仍不够，优先缩减任务名字号，保全时间数据。

2. **点位列表溢出**
- **方案**：**按状态分组 + 自动折叠兜底**。
- **具体数值**：将点位分为“异常/巡检中/待命”三组。默认只展开“异常”和“巡检中”组（每组限显3条，超出折叠显示“+N”）；待命组默认折叠。
- **大屏原则**：大屏远距离观看忌讳频繁交互，不要用分页或普通滚动。若极端情况总点位>20个，提供4px宽的半透明细滚动条，悬停才显现，平时不干扰视觉。

3. **轮式指令面板设计**
- **按钮排布**：横向单行排布。主操作（开始/继续）用高亮色（科技蓝），次操作（暂停）用警告色（橙），取消和回充用弱化色（暗灰）并加图标。
- **状态显示**：按钮上方用大字号显示当前车体状态（如“执行中：前往A点 | 进度35%”）。按钮需**动态启用/禁用**（如执行中时“开始”置灰，“暂停/取消”高亮）。
- **失败反馈**：点击后按钮内转圈Loading（2秒超时）。失败时对应按钮边缘红框闪烁1次，面板顶部弹出醒目Toast提示“下发失败：网络超时/设备拒绝”，3秒自动消失。

4. **最容易做错的3点**
- **任务区**：用了CSS单行省略号`...`。大屏看不全等于没写，必须换行或重排。
- **点位区**：用了传统分页。大屏3米外没人去点“下一页”，导致隐藏点位成为信息盲区，必须按状态智能置顶。
- **轮式控制**：5个按钮全部常亮可点。没做状态联动和禁用逻辑，导致按了没反应或误操作，彻底变成“摆设按钮”。
