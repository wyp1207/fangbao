# 模型评审记录 20261028-135610

## 豆包 doubao-seed-evolving

### 短问答
1. **点哪去哪流程与安全**
接口：复用单点goto透传通道（Nav2调`NavigateToPose`，JCROB用厂商原生导航接口）；流程：选车→点选像素转地图世界坐标（与点位库同坐标系）→校验→透传车端。
强制安全：①已有写开关总闸；②预检（车态正常、电量≥20%、无执行中任务、无急停）；③超出电子围栏/单点距离>30m（可配置）必须二次确认；④车端本地避障/急停兜底。

2. **路径显示规则**
平台严禁自研规划造假。无车端上报时，仅画「目标点虚线直连+实际行驶轨迹实线」，明确标注“目标示意/实际轨迹”，不能宣称是规划路径。
客户要真实规划路径：明确路径由车端SLAM生成，需车端开放全局路径上报（Nav2可直接取`/global_plan`话题，JCROB需厂商定制开放，上报频率≥1Hz），平台原样渲染、标注“车端规划路径”，不补全、不修改。

3. **「匹配地图」与校验**
定义：任务所有点位所属地图，与车端当前加载的SLAM地图完全一致。
强制校验三项：①所有点位`map_id`=车端实时上报的激活`map_id`；②点位落在当前地图有效栅格内（非未知/障碍区，精度阈值±0.1m）；③点位绑定的地图版本hash与车端上报hash一致；任一不符直接驳回任务。

4. **2D/3D共存交互**
首页默认2D全屏（适配高频巡检操作），右上角悬浮**可收起的3D实时小窗**（仅显示机器人位姿、轨迹）；点小窗一键切换全屏3D，2D缩为同位小窗；双视图联动：选车、选点、下发任务时视角、选中态、数据完全同步；保留原独立3D页入口。

5. **最易翻车Top3**
① 2D/3D/车端SLAM三端坐标系（原点、分辨率、转角）不统一，点选偏移、导航错位；
② JCROB等封闭机型不开放规划路径接口，被迫造假路径引发信任问题；
③ 地图更新/机器人换层后`map_id`、版本hash不同步，点位错配导致撞障。

6. **优先做1件事**
打通**车端地图信息上报+2D点选goto安全闭环**（含map_id/版本校验、写开关、预检、超距确认），3D嵌套、真实路径显示后置。
