# 模型评审记录 20261028-135528

## 智谱 glm-5.2

1. **点哪去哪接口/流程与安全**
**流程**：地图点击取坐标(x,y,theta,map_id) -> 预检 -> 调用单点 goto 接口下发 -> 轮询状态。
**安全必加**：①**写开关**（非授权用户禁用）；②**预检**（电量>20%、无急停、非故障态）；③**二次确认**（弹窗显示目标坐标）；④**距离限制**（如单次直线距离<50m，防跨区误触）。

2. **路径显示怎么做才诚实**
**诚实做法**：平台只画“起点-终点直线虚线” + 机器人实时上报的“实际轨迹实线”。
**答客户**：平台不跑算法，规划路径由机器人 Nav2 实时计算。若强求展示，可订阅解析机器人端 `/plan` 话题画线，但需声明此为“动态局部规划”，随时会因避障变道，以实际轨迹为准。

3. **“匹配地图”具体指什么与校验**
**含义**：确保下发的目标点在机器人**当前实际激活的 SLAM 地图**坐标系内，防止坐标体系不重合导致乱跑。
**平台校验**：①**map_id 校验**（平台下发 map_id == 机器人上报 current_map_id）；②**版本校验**（地图修改时间戳/hash 比对）；③**点位合法性**（查 2D 栅格值，校验目标点非障碍物、非未知区域）。

4. **3D与2D共存交互方案**
**方案：2D 主屏 + 3D 悬浮小窗联动**。
2D 栅格图作主操作底图（轻量、易点选）；右上角开 3D 小窗。2D 点击“点哪去哪”时，3D 小窗相机自动平移聚焦该坐标，同步展示机器人实时姿态和周边障碍物。

5. **最容易翻车的3个点**
①**坐标系偏移**：2D 像素坐标、3D 世界坐标、SLAM 物理坐标变换矩阵算错，导致点位漂移；
②**地图版本不同步**：平台更新了底图，机器人端没更新，导致按旧图坐标在新图里撞墙；
③**盲点死等**：点到未探索/狭窄区域，Nav2 规划失败，平台没设 30s 超时机制导致任务卡死。

6. **如果只能先做一件事**
**建立 2D、3D 与 SLAM 地图的统一坐标系及变换矩阵（标定）**。没有这个基准，3D 放不进首页，点哪去哪也是瞎点，一切上层功能免谈。
