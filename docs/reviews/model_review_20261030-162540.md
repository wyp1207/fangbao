# 模型评审记录 20261030-162540

## 豆包 doubao-seed-evolving

### 1. 任务状态区（设计基准1920×1080，适配3-4米观看）
单条采用「左状态标签+中任务名+右剩余时间」弹性布局，单条高48px、条间距8px，区域最多显3条。
- 格式：标签14px/固定宽60px；任务名18px/500字重/行高1.4；剩余时间16px等宽数字，固定宽90px右对齐、设flex-shrink:0。
- 规则：任务名优先级最高，允许自动换2行，仅超2行加省略号；**剩余时间严禁截断/省略**；超3条配4px宽、hover才显隐的半透明白色细滚动条。

### 2. 巡检点位列表
固定原6条区域高度（共304px：单条高44px+条间距8px），选「状态分组+默认折叠+组内滚动」，**不做分页/自动轮播**：
- 异常/告警点全量展开、红标永久置顶；巡检中点默认露3条；待巡检/离线点折叠为1条汇总栏（标注总数），点击展开。
- 组内超高度出4px半透明细滚动条，无永久滚动条破坏科技风。

### 3. 轮式指令面板
彻底移除方向键（避免灰化像摆设），从上到下排布：
- 状态行：10px状态圆点+16px实时文案（如「执行中：2号厂房路线 37%」），先告知车体当前状态。
- 按钮区：主按钮1个（120×40px，随状态切换：待机显「开始任务」/执行中显「暂停」/暂停显「继续」）；下方横排2个次按钮（各88×36px：回充、取消），仅状态匹配时可点，无无效灰按钮。
- 反馈：点击后立刻进「下发中」loading态，2s超时判失败，按钮下方出12px红字原因（如网络中断/车体繁忙），停留3s消失；成功后即时刷新按钮状态。

### 4. 核心易错点
① 任务区为塞内容压缩字号、硬排一行，乱加省略号截断剩余时间核心信息；
② 点位做自动轮播/分页导致异常漏看，滚动条过粗违和、过细无感知；
③ 轮式区照搬云台保留灰化方向键，全指令常驻灰显像故障，缺操作反馈。
