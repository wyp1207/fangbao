## 2. 面板结构

- 整个「实时消息」是一个**大矩形容器**，外层为深藏蓝底，内部嵌一个亮蓝描边的功能面板。
- **顶部标题条（"实时消息"）**
  - 居中放置文字「实时消息」，金黄色 `#FFC23C`、加粗、带轻微发光/浮雕。
  - 标题条不是平直矩形：左右两端有**斜切/折角的科技装饰线**，形成中间宽、两端向下收的「徽章/机甲肩甲」轮廓；中间文字下方有一小段橙黄色短横条 `#F5A623`。
  - 标题区有**横向蓝渐变 + 顶部一道亮青/浅蓝高光线**，呈现镀铬发光条效果。
- **边框**
  - 外框约 **2px 亮蓝 `#2388D8`**，部分边缘可见近乎 **1px 更亮的青色内高光 `#46B8FF`**；四角以直角/极小圆角为主（截图中接近 4–6px）。
  - 面板内部各分区再用 **1px `#1C5E9E` / `#2680C8`** 的细线分隔。
- **内边距**：标题到内容约 10–14px；Tab 区距离左右边缘约 12–16px；右侧任务卡片内边距约 14–18px。
- 顶部「今日任务状态」是一个**独立浅青蓝按钮/标签**：填充 `#36CBE6`、深色文字 `#06264A`、直角带 1–2px 亮边，浮于面板右上。

## 3. 表格（巡检消息列表）

- 左上有三个 Tab：**巡检消息 / 告警消息 / 控制消息**
  - 选中态：亮青底 `#2FE0F0` + 深色字 `#06253F`，字重粗；
  - 未选中：深蓝底 `#0A2247` + 浅蓝字 `#BFD9EF`，边框为蓝色线；
  - Tab 基本为**矩形带极小圆角（2–4px）**，三个并排、间距约 2–4px。
- 表格两列：**「时间」｜「巡检消息」**
  - 表头底色：深蓝 `#0A244B`，比数据行更深，白字加粗。
  - 数据行底色：统一为面板蓝 `#0C2E5B`；截图中**没有明显斑马纹**，靠横向分隔线区分。
  - 分隔线：**1px 亮蓝 `#2574BB`** 的横线和列竖线，网格感清晰。
  - 文字颜色：时间、内容均为近白 `#EAF3FF`，其中「正常」为白色（未变绿），关键检测值 `7.5℃` 也是白/浅色。
  - 字号：正文约 **20–22px（截图被放大拍摄，实际系统约 16–18px 视觉等价）**，字重 600–700，偏粗、保证远距离可读。
  - 行高：较大，约 **56–64px（拍摄图尺度）**，即文字上下有充足 padding（约 14–18px）；长文本自动换行，单元格垂直居中。
- 右侧有一条**宽滚动条**，说明消息区可纵向滚动；滚动条紧贴消息表格右缘。

---

## 4. 右侧任务区

- 与左侧消息列表之间有 **2px 左右亮蓝竖向分隔边框**，本身是一块同色深蓝面板。
- 信息以「**标签（浅青蓝）+ 值（橙黄）**」横向成对排列，每行一条：
  - `任务名称` 青蓝 ｜ `任务测试20250303` 橙黄、加粗
  - `任务状态` 青蓝 ｜ `正在执行` 橙黄、加粗
  - `当前任务预估剩余时间` 青蓝 ｜ `00:12:35` 橙黄、加粗、等宽数字感
- 标签与值之间靠空格/约 12–16px 间距，无冒号也能区分。
- **计数区**：下方三个并排小卡片/单元，单元内是大号数字：
  - 第一组：`1 / 0 / 1`，颜色依次为 **红 / 红 / 绿**
  - 第二组：`0 / 0 / 0`，颜色依次为 **红 / 红 / 绿**
  - 第三组：`0 / 0 / 8`，颜色依次为 **红 / 红 / 亮绿**
  - 数字非常大、加粗、带轻微外发光，斜杠 `/` 为浅色；
  - 每组下方有小字说明：`总数/待执行/已终止/异常/正常`、`告警/异常/正常`（图中文字与三数字对应略有截断，以实际可见为准），说明字为浅蓝白、字号小。
- 三个计数单元之间用 **1–2px 亮蓝竖线**分隔；单元底色与面板一致或略深，边框形成方格。

## 5. 字体感觉

- 全部为**无衬线工业黑体**（接近思源黑体 / 微软雅黑 / HarmonyOS Sans 风格），数字 `00:12:35` 呈现**等宽/表格数字**观感，但中文并非等宽字体。
- 字重层级：标题与数值 **Bold(700)**；表头、Tab 选中 **SemiBold/Bold**；正文消息 **SemiBold(600)**；底部注释 **Regular/Medium(400–500)**。
- 全角中文为主，英文/数字使用拉丁字形；**没有全大写**（中文界面）；字间距为默认/略松（约 0–1px），标题「实时消息」字间距稍大以居中稳重。
- 字号层级（按截图相对比例）：
  1. 计数数字 最大
  2. 顶部标题 / 消息正文与时间
  3. 任务值（橙黄）
  4. 字段标签、表头
  5. 计数区注释小字 最小

## 6. 发光 / 描边 / 渐变用法

**有 glow / 高光：**
- 面板外边框：亮蓝线 + 内侧青白高光，形成「**霓虹描边**」。
- 顶部标题条：横向蓝渐变，顶部有一条亮青/白蓝高光线，文字金色带轻微阴影发光。
- 「实时消息」金字：下方橙黄短装饰条 + 文字投影。
- 右上「今日任务状态」浅青块：边缘有亮边，呈自发光按钮感。
- 计数大数字（尤其绿色「正常」）有轻微外发光，增强跳读。
- 活动 Tab 亮青块颜色最亮，近似发光填充。

**无明显 glow：**
- 表格普通正文、时间文字基本无发光，只靠高对比浅色。
- 普通分隔线只是平的亮蓝线，不做模糊光晕。
- 背景大面积为**平涂深蓝**，未见全局复杂渐变，主要渐变集中在标题条。

---

## 7. 「显专业」的三个关键细节

1. **双层次蓝边框 + 顶部机甲风标题条**：外亮蓝/内暗线的描边、斜切角与顶部高光线，立刻区别于普通后台表格，建立「工业驾驶舱」识别度，同时仍保持规整。
2. **强语义化色彩与「标签冷色 / 数值暖色」体系**：说明文字统一青蓝，关键任务值统一橙黄；状态计数严格用红=异常/待处理、绿=正常，使操作员一眼扫到状态，而不会满屏花哨颜色。
3. **高密度但呼吸感充足的实时数据排版**：带时间戳的滚动事件流 + 右侧任务状态 + 大号 `数字/数字/数字` 汇总格，既像真实运行系统，又通过粗字、大行距、网格线保证监控场景下的可读性。

## 8. 用于 1440×900 驾驶舱的三栏比例建议

结合本区域（消息+任务）适合放在底部或右下，建议整体三栏：

- **视频栏：30%（约 432px）**
- **地图栏：44%（约 634px，最大中心区）**
- **右侧数据栏：26%（约 374px）**

即黄金区域给地图/态势；视频放多路画面；右侧放任务、指标、告警。

底部「实时消息」通栏时，建议内部分栏比例：
- **左侧巡检/告警消息表格：约 62–64%**
- **右侧今日任务状态：约 36–38%**（与截图中消息区宽、任务区窄的观感一致）。
底部消息区高度建议占总高 **22–26%（约 200–230px）**，上方留给视频/地图。

### 工业巡检平台视觉设计说明书

#### 1. 整体色板
工业风驾驶舱通常采用低明度、低饱和度的深色系以减少视觉疲劳，并通过高对比度的文字和强调色突出数据。
*   **主背景**: `#0B0F1A` (极深的幽蓝黑)
*   **面板背景**: `#111726` (稍浅的深邃蓝)，通常带90%不透明度以透出底图网格
*   **标题条背景**: `#1A2336` 或 渐变 `linear-gradient(90deg, #1A2336 0%, transparent 100%)`
*   **主文字**: `#E5EAF3` (略带冷调的白)
*   **次要文字/标签**: `#8A9BAE` (灰蓝)
*   **禁用/极次要文字**: `#5A6B7E`
*   **强调色 (主青/科技蓝)**: `#00E5FF` (用于关键数据、图标、当前选中项)
*   **警示色 (琥珀/黄)**: `#FFB300` (用于告警、待处理状态)
*   **危险色 (赤/红)**: `#FF4D4F` (用于严重故障、阻断状态)
*   **成功色 (绿)**: `#52C41A` (用于在线、正常状态)

#### 2. 面板结构
*   **标题条形状**: 无明显圆角，采用**梯形/斜切角**设计。左侧通常带有一条 2px 的发光立柱（`#00E5FF`），标题文字位于立柱右侧。背景为从左至右的渐变褪色。
*   **边框**: 1px solid `#2D3A55`。科技感面板通常在右上角和左下角带有“L”型或“缺口”状的装饰角线（颜色同边框或略亮）。
*   **内外边距**: 面板内边距通常为 `16px 20px`。面板外部的间距为 `12px` 或 `16px`。
*   **圆角**: 极小或无圆角（`border-radius: 2px` 或 `0px`），保持工业仪器般的冷硬感。

#### 3. 表格设计 (实时消息区)
*   **表头底色**: 透明或 `#1A2336`，无下边框，但有一条 1px 的 `#2D3A55` 分隔线。
*   **行底色**: 纯透明，无斑马纹（斑马纹在深色背景下容易显得脏）。偶数行可带 `rgba(255,255,255,0.02)` 的极微弱提亮。
*   **分隔线**: 行与行之间使用 1px 虚线或极细实线，颜色为 `rgba(45, 58, 85, 0.5)`。
*   **字号与字重**: 表头 `12px`，字重 `Normal`，颜色 `#8A9BAE`。正文 `13px`，字重 `Medium`，颜色 `#E5EAF3`。
*   **行高**: 紧凑型排列，行高通常在 `36px - 40px` 之间。

#### 4. 右侧任务区
*   **字段排布**: 标签（如“任务总数”）与数值水平居中对齐或左右两端对齐。标签在左（`#8A9BAE`），数值在右（`#E5EAF3` 或 `#00E5FF`）。
*   **数字强调**: 核心数字使用等宽字体（如 Din Alternate, Roboto Mono），字号放大至 `24px - 28px`，字重 `Bold`。
*   **计数区分隔与配色**: 多个统计方块之间使用 1px 的半透明竖线（`#2D3A55`）分隔。每个方块的数字下方通常带有一个微型趋势条或极小的状态指示灯（如绿点代表进行中）。

#### 5. 字体感觉
*   **字体族**: 全局无衬线体，推荐 `PingFang SC`, `Microsoft YaHei`。**数字部分强制使用等宽字体**（如 `Roboto Mono` 或 `DIN`），确保数据跳动时面板宽度不抖动。
*   **字号层级**: H1(面板标题) `16px`；H2(区块标题) `14px`；Body(正文/表格) `13px`；Caption(标签/说明) `12px`；Data(大数字) `24px+`。
*   **大小写与字间距**: 英文文案首字母大写。对于纯英文标签（如 STATUS, TASK ID），通常全大写，并增加字间距 `letter-spacing: 0.05em`，以增加呼吸感和高级感。

#### 6. 发光/描边/渐变的具体用法
*   **有 Glow 的元素**: 
    * 标题条前方的指示立柱（`box-shadow: 0 0 8px #00E5FF`）。
    * 当前告警/进行中任务的状态圆点（`box-shadow: 0 0 6px currentColor`）。
    * 关键的大数值数字（带极轻微的 `text-shadow: 0 0 10px rgba(0, 229, 255, 0.3)`）。
*   **无 Glow 的元素**: 普通正文文字、表格边框、次级图标（避免满屏发光导致失去视觉焦点，产生“廉价光污染”）。
*   **渐变**: 面板背景常带 `linear-gradient(180deg, rgba(26,35,54,0.8) 0%, rgba(17,23,38,0.8) 100%)`。按钮或标签背景常使用从下到上的微弱渐变以模拟物理材质。

#### 7. 这个界面“显专业”的三个关键细节
1.  **克制的发光与色彩层级**：不滥用高饱和度颜色，只有最核心的实时数据和状态点发光，次要信息保持灰蓝退后，视线引导极其清晰。
2.  **硬朗的几何切角与边框装饰**：面板边缘的切角和装饰线（如直角折线）去除了普通网页的圆润感，赋予了工业控制台特有的“精密仪器”感。
3.  **等宽数字字体的严格使用**：所有数据、时间戳、ID均使用等宽字体对齐，不仅防止数据刷新时的布局抖动，更在视觉上形成了严谨的工程美学。

#### 8. 1440×900 驾驶舱三栏比例建议
在 1440×900 的分辨率下，高度相对局促。为了保证视频的沉浸感、地图的可用性以及右侧数据的可读性：
*   **左侧 (视频区)**: `40%` (约 576px) —— 保障巡检画面的细节看清。
*   **中间 (地图/全景区)**: `30%` (约 432px) —— 保持地图核心区域不被过度压缩。
*   **右侧 (数据/实时消息)**: `30%` (约 432px) —— 刚好容纳 3 列数据统计和紧凑的实时消息列表。
*(注：面板之间需预留 12px-16px 间距)*
