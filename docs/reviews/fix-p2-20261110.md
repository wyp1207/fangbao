## 「接着跑」语义（需产品确认，先按此实现）

后端 `from_seq` 是**闭区间**起点（`server/app/services/cruise.py:97-98`：`TaskRunStep.seq >= from_seq`），
所以前端传 `最后完成 seq + 1`，即**从最后完成点的下一个点继续**，不重跑已完成的点。
若产品要求"重跑中断/最后完成的那个点"，把 `resumeFromFailed()` 里的 `+ 1` 去掉即可（一行）。
本次按"从断点继续"实现，已在此注明。
