## 4. 图片 URL 鉴权结论

实测同一张图片（`/dw/.../alarm_..._Picture.jpg`）：

| 请求 | 状态码 | 字节数 | Content-Type |
|---|---|---|---|
| 带 `Authorization: Bearer <accessToken>` | **200** | 507,387 | `image/jpeg` |
| 不带 Authorization | **200** | 507,387 | `image/jpeg` |

结论：
1. **Bearer 可取**：token 有效，图片 GET 成功，后续可以按需下载/落盘。
2. **当前部署不强制鉴权**：同一 URL 不带 token 也返回 200。图片路径在局域网内可被未认证访问，
   属于现场安全项；平台侧仍应统一带 Bearer，并建议对 8081/图片路径做 IP 白名单。
3. Phase 4 按约定**不下载图片**，只把绝对 URL 存进 `ai_result.result_json`；下载能力已实现并有单测。
