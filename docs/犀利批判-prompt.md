## 我们做了什么（别信我们的自述，可以质疑）
- FastAPI + MySQL + Vue3 单机部署，Docker Compose
- 设备接入：云深处 X30（TCP 30000 读状态、UDP 43893 起立）+ JCROB（HTTP 3546，目前是模拟器）
- 外设模型：peripheral 表（camera/thermal/ptz/gas/temp/humidity/noise/dust），能力由外设派生（video.live/video.thermal/ptz.move/env.read.*/posture.*）
- 首页：按能力渲染面板；实时消息三 tab（巡检/告警/控制），点击跳详情并高亮
- 告警：阈值（外设规则优先）+ 去重 + 5 分钟内多次升级 + 条件消失自动恢复；告警↔工单双向可查
- 工单：派单、手机 H5 接单拍照销号、超时升级、企业微信/钉钉/Webhook 推送（带签名重试）
- 任务：模板→执行记录→巡航（平台逐点下发 + 轮询 1007/HTTP 状态 + 到点动作）；写开关默认关
- 视频：go2rtc + ffmpeg 分段录制（最多 2 路）
- 报表：巡检/考核/覆盖度/响应闭环（确认时长、建单时长、闭环率）、Excel/PDF
- 安全：7 角色、三权分立、TOTP、登录锁定、密码历史、审计哈希链、API Key
- 运维：/metrics、日志落盘 180 天、备份脚本
- 已知：真机巡航没跑过、到点拍照接口没对接、PTZ 控制没做、JCROB 真机没到
