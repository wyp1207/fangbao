feat(task): 任务互斥锁 + 人工接管（两人同时下发 / 巡航中手动开车的场景）

背景：之前同一台车可以同时下发两条任务，谁先谁后无保证，车会来回横跳；
巡航中有人想手动把车开回去，也没有抢占机制。

新增 services/task_lock.py：
- active_run(db, robot_id)：该车当前 running 的任务
- assert_free()：下发/巡航前检查，占用则 409 RUN_BUSY，提示"还在执行任务 #id「名称」"
- takeover()：把该车所有 running 任务置 cancelled（原因写进 dispatch_error）

接线：
- task_dispatch.dispatch 与 POST /task-runs/{id}/cruise 之前都过 assert_free
- 新增 POST /robots/{id}/takeover（admin/operator/safety），写审计 robot.takeover
- 首页"起立/趴下"前先调 takeover（提示"已接管，取消 N 条运行中任务"）
- 任务执行页 running 行加「接管」按钮（二次确认）

测试：tests/test_task_lock.py 3 例（第二次下发被拦、接管取消两条、无运行任务不拦）
验证：89 用例通过
