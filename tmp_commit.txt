feat(x30): 真机基础运动打通 + 平台车体控制（起立/开始运动/方向盘/停止）

真机实测（只读+用户确认场地清空后的小幅动作）：
- 起立 UDP 0x31010202：MotionState 0→1→2（脚本与平台 API 各一次）
- 开始运动 0x31010201：2→4（踏步）
- 前进 0x21010130（forward=0.3，10Hz 重发 1s）：位姿变化，松手零速
- 停止运动：一次没回站立，需再发/等待（已记录待优化）

平台能力：
- POST /robots/{id}/motion-mode {stand|lie|start|stop}：写开关 + 审计
- POST /robots/{id}/move {forward,left,yaw}：归一化 [-1,1] -> 轴值（跳过 |655| 死区），
  每帧独立、松手发 0；MotionState 不在 2/3/4 直接 409；审计 2 秒节流
- 适配器新增 toggle_motion / move_axis；状态里补 motion_state 原始值
- 首页「实时控制 -> 车体控制」换成方向盘：▲▼◀▶ + 转向 + 停止，按住走、松手停
