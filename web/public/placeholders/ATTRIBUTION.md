# 占位素材说明

这些图只用于 UI 占位，**不是现场画面**，界面上必须标注“示例 / 占位”。

| 文件 | 来源 | 许可 |
|---|---|---|
| `robot-inspection.jpg` | [ANYmal inspection power grid](https://commons.wikimedia.org/wiki/File:Anymal-robot-inspection-power-grid.jpg)，Wikimedia Commons | 以文件页标注为准（CC BY-SA） |
| `thermal.jpg` | [Thermal image on a tablet](https://www.pexels.com/photo/a-thermal-image-on-a-tablet-7859787/)，Pexels | Pexels License |

使用位置：

- 首页“可见光视频”无流时：显示 `robot-inspection.jpg` + 「示例画面 · 占位」
- 首页“热红外视频”无流时：显示 `thermal.jpg` + 「热成像示例 · 占位」
- 告警无证据图时：不冒充现场图，显示“无证据图”

替换真实图后删除本目录即可。
