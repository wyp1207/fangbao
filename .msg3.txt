feat: 告警→录像回看 + 外发签名与重试 + 接口限流

告警回看：
- 告警列表对有 camera_id 的记录显示「▶ 看录像」
- 跳转 /record/playback?video=&date=&t=，回放页按 query 预选摄像头/日期/时刻
- 实测：AI 告警点开 → video=1&date=2026-10-22&t=14:43:54

外发安全与可靠：
- Webhook 加 HMAC 签名：X-Jcrob-Timestamp + X-Jcrob-Signature=sha256(hmac(secret, ts.content))
  接收方可校验来源与完整性；secret 可在通道配置里单独设，默认用平台密钥
- 发送改为 content=raw（签名对字节算，不能先 json 再让 httpx 重编码）
- 投递失败落库：notify_log 增加 payload_json / attempts / next_retry_at
- 调度器每分钟重投失败项（最多 3 次，间隔 2/4 分钟），进程重启不丢
- 实测：签名可被 python 端复算一致；失败记录重投后 ok=True、attempts=2、next_retry_at 清空

限流：
- nginx 按 API Key 分桶（无 Key 按 IP），rate=20r/s burst=40，超限 429
- nginx -t 校验通过

验证：57 个后端用例通过（新增签名与重试用例）
