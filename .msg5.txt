feat(security): 审计哈希链 + 双因子（TOTP）

都是照现成标准做的，没有自己发明：
- 审计链用"每行 hash 串上一行 hash"的通用做法（改一行/删一行都会断链）；
  row_hash = sha256(prev_hash + 固定字段串)，GET /audit-logs/verify 逐行复算
- 老记录（上线前无哈希）按 legacy_rows 跳过，不算断链，避免历史数据把校验搞崩
- TOTP 按 RFC 6238 用标准库实现（hmac/sha1/struct），不引 pyotp；
  已用 RFC 测试向量核对：secret 1234567890... @ T=59 → 287082 ✓

双因子：
- user 增加 totp_secret / totp_enabled（0014）
- /auth/totp/start 生成密钥与 otpauth:// 链接；/enable 校验后开启；/disable 需密码
- 开启后登录必须带 totp_code，否则 401 TOTP_REQUIRED；错码 TOTP_INVALID
- 前端：登录页出现动态码输入框；头像菜单「双因子认证」扫码/手输密钥后输码开启

审计链：
- operation_log 增加 prev_hash / row_hash（0013）
- audit() 统一算链（唯一写入口），verify 接口 admin 可查

验证：60 个后端用例通过（新增篡改检测、TOTP 全流程）；实测改一行 → broken_at 指到该行
